---

## 🚀 Como executar localmente

1. Clone o repositório:
   ```bash
   git clone https://github.com/felipemanchester/forest.git
   ```
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Gere/observe o CSS do Tailwind:
   ```bash
   npm run tailwind
   ```
4. Abra `index.html` no navegador.
